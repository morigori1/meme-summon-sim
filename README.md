# ミーム召喚儀式バトル

インターネットミームを召喚して戦う、ブラウザベースの一人用バトルシミュレーター。

## 概要

プレイヤーは儀式師となり、実在するインターネットミームを召喚し、一対一の召喚バトルを行います。
半熟ヒーロー風の誇張された演出とコメディ要素を持つ、ワンセッション完結型のプロトタイプです。

## 特徴

- **文脈駆動型バトル**: ミームの威力は戦場の「空気」（文脈タグ）との適合度で変化
- **鮮度システム**: 使い込むほどミームの鮮度が落ち、威力が減衰
- **読み合いコマンド**: 攻撃・フェイント・チャージの三すくみ
- **QTEイベント**: 儀式発動時とクリティカルチャンス時にタイミングQTE
- **豊富なミーム**: 日本のネット文化（野獣先輩、ぬるぽ、ブロントさん等）と海外ミーム（Rickroll、Doge等）

## 遊び方

1. ブラウザでゲームを開く
2. 現在の戦場の空気（文脈タグ）を確認（ランダム生成された戦場）
3. 召喚するミームを選択（文脈適合度・固有特性・必殺技を確認）
4. 多段階召喚儀式を実行
   - **第一段階**: 召喚陣準備
   - **第二段階**: 詠唱（選択したミームのキャッチフレーズ・由来が表示される）
   - **第三段階**: 力の集中（SPACE キーでQTE）
   - 成功すると先制ボーナス獲得
5. 毎ターン、コマンドを選択して戦闘
   - **攻撃**: 相手にダメージ（各ミームの必殺技と台詞が発動）
   - **フェイント**: 相手の攻撃を無効化
   - **チャージ**: 次ターンの攻撃を強化
6. 各ミームの固有特性が戦闘に影響
7. 勝利、敗北、引き分けのいずれかで結果表示

## 技術仕様

- **言語**: バニラJavaScript (ES6+)
- **構成**: 
  - `index.html` - メインHTML（UI構造とスタイル）
  - `memes.js` - ミームデータベースと文脈システム
  - `qte.js` - QTE（クイックタイムイベント）管理
  - `game.js` - メインゲームロジック
- **依存関係**: なし（外部ライブラリ不使用）
- **対応ブラウザ**: モダンブラウザ（Chrome, Firefox, Safari, Edge）

## ローカル実行方法

### 方法1: Pythonの簡易サーバー

```bash
# Python 3の場合
python3 -m http.server 8765

# ブラウザで開く
# http://localhost:8765
```

### 方法2: Node.jsの簡易サーバー

```bash
# npxでhttp-serverを使用
npx http-server -p 8765

# ブラウザで開く
# http://localhost:8765
```

### 方法3: 直接ファイルを開く

多くのブラウザでは `index.html` をダブルクリックして直接開けます。
（一部の機能が制限される可能性があります）

## ライセンス

このプロトタイプは実験的プロジェクトです。
使用されているミームは文化的参照であり、著作権のある画像・音声は使用していません。

## 注意事項

- 野獣先輩などのミームについては、実在の人物とミームキャラクターを区別して扱っています
- 商標・著作権を侵害しないよう、テキストとシンボルのみで表現しています
- 純粋にインターネット文化への敬意を込めた作品です
