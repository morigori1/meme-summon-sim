# ミーム召喚儀式バトル

インターネットミームを召喚して戦う、ブラウザベースの一人用バトルシミュレーター。

## 概要

プレイヤーは儀式師となり、実在するインターネットミームを召喚し、一対一の召喚バトルを行います。
半熟ヒーロー風の誇張された演出とコメディ要素を持つ、ワンセッション完結型のプロトタイプです。

## 特徴

- **文脈駆動型バトル**: ミームの威力は戦場の「空気」（文脈タグ）との適合度で変化
- **鮮度システム**: 使い込むほどミームの鮮度が落ち、威力が減衰
- **読み合いコマンド**: 攻撃・フェイント・チャージの三すくみ
- **QTEイベント**: 儀式発動時とクリティカルチャンス時にタイミングQTE
- **豊富なミーム**: 日本のネット文化（野獣先輩、ぬるぽ、ブロントさん等）と海外ミーム（Rickroll、Doge等）

## 遊び方

1. ブラウザでゲームを開く
2. 現在の戦場の空気（文脈タグ）を確認（ランダム生成された戦場）
3. 召喚するミームを選択（文脈適合度・固有特性・必殺技を確認）
4. 多段階召喚儀式を実行
   - **第一段階**: 召喚陣準備
   - **第二段階**: 詠唱（選択したミームのキャッチフレーズ・由来が表示される）
   - **第三段階**: 力の集中（SPACE キーでQTE）
   - 成功すると先制ボーナス獲得
5. 毎ターン、コマンドを選択して戦闘
   - **攻撃**: 相手にダメージ（各ミームの必殺技と台詞が発動）
   - **フェイント**: 相手の攻撃を無効化
   - **チャージ**: 次ターンの攻撃を強化
6. 各ミームの固有特性が戦闘に影響
7. 勝利、敗北、引き分けのいずれかで結果表示

## 技術仕様

- **言語**: バニラJavaScript (ES6+)
- **構成**: 
  - `index.html` - メインHTML（UI構造とスタイル）
  - `memes.js` - ミームデータベースと文脈システム
  - `qte.js` - QTE（クイックタイムイベント）管理
  - `game.js` - メインゲームロジック
- **依存関係**: なし（外部ライブラリ不使用）
- **対応ブラウザ**: モダンブラウザ（Chrome, Firefox, Safari, Edge）

## ローカル実行方法

### 方法1: Pythonの簡易サーバー

```bash
# Python 3の場合
python3 -m http.server 8765

# ブラウザで開く
# http://localhost:8765
```

### 方法2: Node.jsの簡易サーバー

```bash
# npxでhttp-serverを使用
npx http-server -p 8765

# ブラウザで開く
# http://localhost:8765
```

### 方法3: 直接ファイルを開く

多くのブラウザでは `index.html` をダブルクリックして直接開けます。
（一部の機能が制限される可能性があります）

## 最新の更新内容

### v0.2.0 - ミーム個性強化 & 儀式演出追加

**各MEMEの個性化**
- 全ミームにキャッチフレーズ、由来（lore）、必殺技名を追加
- 戦闘中の台詞（攻撃/フェイント/チャージ時の固有セリフ）
- ユニークな特性（パッシブ効果）を実装:
  - 野獣先輩: 語録テンプレ（攻撃成功で鮮度回復）
  - ぬるぽ: 即応（フェイント成功で反撃ダメージ）
  - ブロントさん: ナイト様（チャージ攻撃倍率強化）
  - 八頭身モナー: 不気味（攻撃時に相手の鮮度を削る）
  - トンファー: 武術（連続攻撃でダメージ累積）
  - CCO: 空耳（特定戦場でダメージボーナス）
  - Rickroll: 不意打ち（初ターン攻撃強化）
  - This is fine: 平然（低HP時の被ダメージ軽減）
  - Leeroy Jenkins: 突撃（高火力・高リスク）
  - Doge: such wow（ランダムボーナス）

**ステージランダム生成**
- 固定リストから選択ではなく、毎回異なる戦場名を生成
- 雰囲気語 + 場所語の組み合わせ（例: 「荒廃した闘技場」「電脳の回廊」）
- タグも2〜4個をランダム選択

**儀式フェーズの強化**
- 多段階召喚儀式（準備→詠唱→QTE→召喚）
- 回転する魔法陣風ビジュアル
- 選択したミームのキャッチフレーズと由来を儀式中に表示
- パーティクルエフェクト
- 詠唱ゲージアニメーション
- 成功時のフラッシュエフェクト
- Google Fonts（Noto Sans JP + Press Start 2P）による視覚強化

**UI改善**
- カード選択画面に必殺技名・固有特性・由来要約を表示
- 戦闘ログに各ミームの台詞を追加
- 結果画面にキャッチフレーズ表示

## ライセンス

このプロトタイプは実験的プロジェクトです。
使用されているミームは文化的参照であり、著作権のある画像・音声は使用していません。

## 注意事項

- 野獣先輩などのミームについては、実在の人物とミームキャラクターを区別して扱っています
- 商標・著作権を侵害しないよう、テキストとシンボルのみで表現しています
- 純粋にインターネット文化への敬意を込めた作品です
